Decisions

Settled for now

  • SmactorIO is the umbrella autonomous project operating system name for now.
  • Signal Hub remains the private LAN dashboard/control surface inside SmactorIO.
  • The homepage is the cockpit; the roadmap, contract, and journal hang from it.
  • The homepage must stay neat and link to details instead of becoming a wall of text.
  • The basic automation loop comes before advanced self-improvement machinery.
  • Prioritization is a standalone governed step between normalization and candidate selection.
  • GitHub Issues/branches/PRs become the canonical backlog/version-control path; tarballs are not normal rollback.
  • The first GitHub-backed Candidate is bootstrap-github-backed-smactorio-source-001.
  • Direct main pushes are not allowed for the bootstrap autonomy slice; use branch + PR.
